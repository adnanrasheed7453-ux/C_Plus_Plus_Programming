# C++ Sample Quiz Questions

This repository contains a collection of **30 simple C++ sample questions** for quiz preparation and programming practice.

## Questions Included

* Question 01 to Question 30
* Basic C++ programming concepts
* Simple input and output
* Variables and data types
* Operators
* Conditional statements
* Loops
* Basic programming logic
* Simple C++ programs

## Purpose

These questions are provided as **sample practice questions** to help students prepare for C++ quizzes and improve their basic programming concepts.

They can also be useful for juniors who want to practice simple C++ questions before their quizzes.

## Language Used

* C++

## Level

**Beginner / Basic C++**
