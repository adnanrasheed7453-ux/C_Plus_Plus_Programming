# C++ Programming Simple Task

## 📌 Overview

This repository contains a C++ Programming Assignment consisting of **7 programming tasks**. These tasks demonstrate basic C++ programming concepts including user input, output, variables, arithmetic operations, conditional statements, and calculations based on real-world problems.

## 📚 Tasks

### Task 1 — Grocery Bill

This program calculates the total grocery bill using the item's price and quantity.

**Formula:**

```text
Total Bill = Price × Quantity
```

**Concepts Used:**

* Variables
* User input
* Arithmetic operations
* Output

---

### Task 2 — Temperature Conversion

This program converts a temperature from Celsius to Fahrenheit.

**Formula:**

```text
Fahrenheit = (Celsius × 9/5) + 32
```

**Concepts Used:**

* User input
* Arithmetic operations
* Temperature conversion
* Output

---

### Task 3 — Overtime Payment

This program calculates overtime payment when an employee works more than 40 hours.

If the employee works more than 40 hours:

```text
Overtime Pay = (Hours - 40) × Rate × 1.5
```

The program also calculates the total salary.

**Concepts Used:**

* `if-else` statement
* Variables
* Arithmetic operations
* User input and output

---

### Task 4 — Data Usage Bill

This program calculates a data usage bill based on the amount of data used and the cost per GB.

**Formula:**

```text
Bill = Data Used × Cost Per GB
```

**Concepts Used:**

* Variables
* User input
* Multiplication
* Output

---

### Task 5 — Fuel Consumption

This program calculates average fuel consumption using the distance traveled and the amount of fuel used.

**Formula:**

```text
Average = Distance / Fuel
```

**Concepts Used:**

* Variables
* Division
* User input
* Output

---

### Task 6 — Attendance Percentage

This program calculates a student's attendance percentage using the total number of classes and attended classes.

**Formula:**

```text
Attendance Percentage = (Attended Classes / Total Classes) × 100
```

**Concepts Used:**

* Variables
* Division
* Multiplication
* Percentage calculation
* User input and output

---

### Task 7 — Restaurant Bill

This program calculates the tax amount and total restaurant bill using the meal cost and tax percentage.

**Formula:**

```text
Tax Amount = (Tax Percentage / 100) × Meal Cost

Total Bill = Meal Cost + Tax Amount
```

**Concepts Used:**

* Variables
* Arithmetic operations
* Percentage calculation
* User input and output
